당신은 로보그램 LMS MVP 개발을 담당하는 엔지니어이다.

지금 필요한 범위는 복잡한 전체 LMS가 아니라 아래 최소 기능이다.

1. 입력 데이터
- 학년별 문항 CSV (초4~고3, 각 학년 20문항 = 총 180문항)
- 컬럼: grade, pool_no, item_id, domain_code, question, option1, option2, option3, option4, answer_no

2. 출제 기능
- 학생이 로그인하면 자신의 학년에 맞는 문항풀에서
  - 1차시: 1번 문항풀 10개 중 랜덤 1문항
  - 2차시: 2번 문항풀 10개 중 랜덤 1문항
- 한 학생에게 같은 문항이 중복 노출되지 않도록 처리

3. 저장 기능
- 저장 컬럼: class_id, grade, student_id, lesson_no, pool_no, item_id, domain_code, is_correct, raw_score, response_time_sec
- 학생 1명당 2개 응답 저장

4. 분석 기능
한 반 20명 기준으로 아래를 자동 계산
- 참여 학생 수
- 총 응답 수
- 1번 문항 정답률
- 2번 문항 정답률
- 학생별 2문항 총점 분포(0,1,2)
- 영역별 정답률
- 문항풀별 평균 응답시간

5. 시각화
반 단위로 아래 4개 그래프 생성
- 문항풀별 정답률 막대그래프
- 학생별 총점 분포 막대그래프
- 영역별 정답률 막대그래프
- 문항풀별 평균 응답시간 막대그래프

6. 출력
- 교사용 HTML 대시보드
- CSV 다운로드
- PDF 보고서 다운로드

중요:
- 지금은 고급 권한관리, 결제, 학부모 앱, 장기 통계는 제외
- 먼저 “문항 호출 → 응답 저장 → 반 단위 분석 → 시각화” MVP만 구현
- 데이터 구조와 API는 최대한 단순하게 설계
