Firebase 연결 설정
RoboEval은 Google Firebase를 사용하여 모든 데이터를 저장합니다.
아래 안내에 따라 Firebase 프로젝트를 생성하고 설정값을 붙여넣으세요.
📋 설정 방법 (5분 소요)
  1. console.firebase.google.com 접속 → 프로젝트 추가
  2. 프로젝트 이름: roboeval 입력 → 생성
  3. 좌측 메뉴 Firestore Database → 데이터베이스 만들기 → 테스트 모드
  4. 좌측 메뉴 Storage → 시작하기 → 테스트 모드
  5. ⚙️ 프로젝트 설정 → 내 앱 → 웹 앱 추가(</>) → 아래 설정값 복사

이 설정값은 이 기기에만 저장됩니다. Firebase 무료 플랜(Spark)으로 충분합니다.
