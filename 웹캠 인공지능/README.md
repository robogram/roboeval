# 📷 웹캠으로 배우는 인공지능 - 성취도평가 문항 시스템

본 디렉토리는 **"웹캠으로 배우는 인공지능"** 과목의 단원별 4지선다 성취도평가 문제 및 시스템 연동 파일들을 포함합니다.

---

## 1. 과목 및 문항 개요

* **과목명**: `웹캠으로 배우는 인공지능` (시스템 식별 키워드: `웹캠`)
* **교재 파일 연계**:
  * 1단원: 얼굴인식 (`face/index.html`)
  * 2단원: 사물인식 (`object/index.html`)
  * 3단원: AI 페르소나 (`persona/index.html`)
  * 4단원: 캡스톤 통합 (`capstone/index.html`)
  * 5단원: 생성형 AI (`textimg/index.html`)
* **문항 구성**:
  * 총 5개 단원 × 단원당 20문항 = **총 100문항**
  * 난이도 구성: 각 단원별 **기초 15문항 + 초중급 5문항** (전체 기초 75문항, 초중급 25문항)
  * 문항 유형: 4지선다 객관식
  * 정답 분포: ① 25문항, ② 25문항, ③ 25문항, ④ 25문항 (완전 균등 배분)

---

## 2. 데이터 스키마 및 원칙 준수 (AGENTS.md)

1. **0-based 정답 인덱스 (`answer: 0, 1, 2, 3`)**:
   * 엑셀 정답지의 1~4 정답 번호에서 1을 뺀 0-based 정수로 저장되어 학생 제출 답안(`responses`, 0-based) 및 다중 오프셋 매칭 공식과 100% 호환됩니다.
2. **문항 객체 필드**:
   * `item_id`: 문항 고유 식별자 (`WEBCAM-AI-Q001` ~ `WEBCAM-AI-Q100`)
   * `raw_id`: 엑셀 원본 문항 ID (`1-01` ~ `5-20`)
   * `day`: 해당 단원 번호 (`1` ~ `5`)
   * `order`: 단원 내 문항 번호 (`1` ~ `20`)
   * `type`: `"객관식"`
   * `content`: 문제 본문
   * `choices`: 4지선다 보기 배열 (`[보기1, 보기2, 보기3, 보기4]`)
   * `answer`: 정답 인덱스 (0, 1, 2, 3)
   * `domain`: 단원 영역명 (`"얼굴인식"`, `"사물인식"`, `"AI 페르소나"`, `"캡스톤 통합"`, `"생성형 AI"`)
   * `diff`: 난이도 (`"기초"` 또는 `"초중급"`)
   * `explanation`: 정답 및 상세 해설
   * `reference`: 교재 근거 파일 및 절

## 4. `index.html` 연동 위치 요약

1. **상수 선언**: `const MASTER_WEBCAM_AI_QUESTIONS = [...]` (100문항 데이터)
2. **과목 선택 옵션**: `<datalist id="subject-list">`에 `📷 웹캠으로 배우는 인공지능` 등록
